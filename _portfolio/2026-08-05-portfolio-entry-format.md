---
title: "How portfolio entries work (template)"
---

This is a sample engineering-portfolio entry showing the format. Each entry is a
Markdown file in `_portfolio/` named `YYYY-MM-DD-short-title.md`.

## Problem

What were we trying to solve? One or two sentences.

## What we tried

The approaches, in order, including the ones that failed and why.

## What we learned

The takeaway that changes what we do next time.

## Evidence

Photos, data, or code links. Images go in `assets/img/` and are referenced like:

```markdown
![Drivetrain v2 under test](/assets/img/drivetrain-v2.jpg)
```
